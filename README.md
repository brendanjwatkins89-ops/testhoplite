# 3D-модель аквариума

Готовая модель лежит в [`models/aquarium.glb`](models/aquarium.glb). Это glTF 2.0 в бинарном виде — формат, который читают Blender, Unity, Godot и three.js.

Что внутри:

- аквариум 100 × 50 × 40 см из стекла 8 мм со швами герметика и чёрным задним фоном, на деревянной тумбе высотой 75 см, со светильником;
- песок, камни с прожилками, галька, коряга со мхом;
- растения: валлиснерия, стелющаяся под поверхностью, людвигия, гигрофила, эхинодорус, криптокорина, анубиас, газон на переднем плане;
- 12 рыб с полупрозрачными плавниками: стайка из семи неонов, три золотые рыбки разной окраски, две скалярии;
- нагреватель, трубки фильтра, распылитель с пузырьками, вода с рябью.

Единицы — метры, ось Y направлена вверх, начало координат — на полу под центром тумбы. Цвета записаны в вершинах; четыре небольшие текстуры (дерево, камень, зерно песка) встроены в файл. В файле одна зацикленная анимация `Aquarium_Loop` на 24 секунды: рыбы плавают и машут хвостами, растения качаются, пузырьки поднимаются, по воде бежит рябь. Объекты названы по смыслу (`Tank`, `Fish_Goldfish_1`, `Plant_Sword_1`, …), так что отдельные части легко найти и убрать.

## Просмотр в браузере

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает команда: вращение — мышью, масштаб — колесом.

Свет лампы, тени, блики на песке и отражения на стекле добавляет сам просмотрщик ([`src/viewer.js`](src/viewer.js)) — в файле модели их нет, и в другой программе освещение будет своим.

## Как изменить модель

Модель строится кодом: [`src/aquarium.js`](src/aquarium.js) собирает её из частей, лежащих в [`src/model/`](src/model) — корпус и тумба, грунт с камнями, растения, рыбы, оборудование, вода. Расстановка задана координатами в этих файлах: камни — в `ROCKS`, растения — в `PLANTING`, маршруты рыб — в `buildFish`. После правок пересоберите файл:

```sh
npm run model
```
