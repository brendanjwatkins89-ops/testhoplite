# 3D-модель аквариума

Готовая модель лежит в [`models/aquarium.glb`](models/aquarium.glb). Это glTF 2.0 в бинарном виде — формат, который читают Blender, Unity, Godot и three.js.

Что внутри:

- аквариум 100 × 50 × 40 см из стекла 8 мм на тумбе высотой 75 см, с рамками и светильником;
- песок, камни, галька, коряга, растения (валлиснерия, людвигия, эхинодорус, газон на переднем плане);
- 12 рыб: стайка из семи неонов, три золотые рыбки, две скалярии;
- распылитель с пузырьками, нагреватель, вода.

Единицы — метры, ось Y направлена вверх, начало координат — на полу под центром тумбы. Текстур нет: цвета записаны в вершинах. В файле одна зацикленная анимация `Aquarium_Loop` на 24 секунды: рыбы плавают и машут хвостами, растения качаются, пузырьки поднимаются. Объекты названы по смыслу (`Tank`, `Fish_Goldfish_1`, `Plant_Sword_1`, …), так что отдельные части легко найти и убрать.

## Просмотр в браузере

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает команда: вращение — мышью, масштаб — колесом.

## Как изменить модель

Модель строится кодом в [`src/aquarium.js`](src/aquarium.js): размеры — в `SIZE` в начале файла, расстановка камней, растений и рыб — в соответствующих функциях `build…`. После правок пересоберите файл:

```sh
npm run model
```
